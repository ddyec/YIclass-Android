## 安装后使用

1. 导入本地PDF，在预览确认首周周一与学校作息，选择课程保存。
2. 设置中开启通知；需要准时提醒时开启精确提醒权限。
3. 长按桌面或通过设置添加YI课表组件。
4. 配置DeepSeek Key，使用右下角书页助手；所有变更先审阅再保存。
